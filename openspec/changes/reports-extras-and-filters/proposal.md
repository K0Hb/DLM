## Why

Админу не хватает операционных и коммерческих сводок: текущая загрузка (воронка статусов / задачи на руках), разрез по заказчикам и по услугам за период. Существующие отчёты (§7.1–7.3) слабо фильтруются — те же срезы, что уже есть в рабочих списках, должны быть и в отчётах.

## What Changes

- Добавить три отчёта (admin/superadmin), все тексты UI на русском:
  - **Воронка / в работе** — счётчики нарядов по статусам; строки услуг «на руках» (assigned / in_progress) по исполнителям
  - **По заказчикам за период** — число нарядов, сумма к оплате / оплачено / долг (по дате создания наряда)
  - **По услугам за период** — объём и начисления по выполненным строкам (по `completed_at`)
- Расширить фильтры существующих отчётов:
  - Список нарядов: статус, заказчик, оплата заказчиком
  - Начисления: сотрудник, выплачено/нет, услуга
  - Долги: заказчик, только с суммой к оплате > 0
- Обновить хаб `/reports` и `spec.md` §7 (новые подразделы + фильтры)
- Integration-тесты на доступ и базовые срезы
